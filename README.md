One funny single-line one-star review written by a house cat about the human it lives with, under 200 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
One star. The human opened the good tuna, ate it himself, then acted shocked when I knocked his laptop off the table.
```
